## 本机启动

需要 Node.js 20或更新版本，无第三方运行依赖。在仓库根目录运行：

```sh
node outputs/first-map-v1/server.mjs
```

或运行 `npm start`。浏览器打开 http://127.0.0.1:4177/first-map-v1/index.html 。服务在本机提供HTTP/SSE组队、战斗和存档接口，可用多个窗口测试。自动生成的个人存档保存在 `work/`，不随源码上传。
