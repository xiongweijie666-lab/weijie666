# 我的修仙日记 · 青竹山麓 · 技能三段成长版 v5

首张可玩的 2D 场景。探索时用摇杆、WASD 或方向键移动；地图不显示野怪，在对应分区移动时随机切换到回合战斗。分区地图可自动沿小径寻路。

地图右下提供技能、装备、队伍、宠物、行囊五个入口；战斗顶部也可打开，面板内可以直接切换。面板打开时停止寻路和摇杆输入，关闭后等待新的移动操作。

## 启动

当前电脑的试玩地址：<http://127.0.0.1:4177/first-map-v1/index.html>。

解压资源包并保留 `outputs` 下的三个文件夹。使用 Node.js 20 或更新版本运行：

```powershell
node outputs/first-map-v1/server.mjs
```

Windows 也可在 PowerShell 中运行 `outputs/first-map-v1/启动青竹山麓.ps1`。脚本优先使用 PATH 中的 Node，当前 Codex 电脑也可使用已安装的内置运行时。服务启动后打开上面的地址；终端中按 Ctrl+C 停止。无须安装 npm 依赖。仅双击 HTML 无法使用队伍和存档接口。

## 五个怪物分区

| 区域 | 怪物 | 等级 |
| --- | --- | --- |
| 花溪草坡 | 团子 | 1 |
| 碧水溪岸 | 乌龟 | 3 |
| 青竹幽径 | 狼 | 6 |
| 赤石山岗 | 野猪 | 10 |
| 灵桃古林 | 猴子 | 15 |

石溪驿站是安全起点。五种怪物均有普通、宝宝、变异三种形象。地图隐藏野怪；在分区内累计移动约96地图单位，进行一次24%的遇敌判定。怪物品质按普通75%、宝宝20%、变异5%随机产生。站着不动、驿站和分区外的小径不会遇敌；胜利返回后保留160地图单位的缓冲距离。组队时由队长移动触发全队共享战斗。

## 队伍

- 最多 5 人。未组队及只有本人时，每场 1—2 只怪。
- 2、3、4、5 人队伍分别为 2—4、3—6、4—8、5—10 只；宠物不增加遭遇数量。
- 队长创建队伍，另一名玩家用六位房号加入。面板的“新窗口加入”会创建独立玩家，可在同一电脑的两个窗口测试共同战斗；可复制房号。
- 剧情同伴可填补空位，界面标明 AI；真人在各自回合选择操作，其他玩家的指令按钮暂时禁用。
- 真人队友加入后需点击“我已准备”；全员准备后由队长移动遇敌。队长可移交给队内真人。五个席位显示职业、等级、在线状态、准备状态与携宠。
- 队长带队触发遭遇、撤退和返回地图。战斗期间及结果画面未返回地图时不能增减队友；技能演出完成后再进行下一次操作。

## 宠物

- 进入战斗，先选择目标，再点击“捕捉”。成功或失败都消耗人物的一次行动。
- 普通、宝宝、变异的基础捕捉率暂定为 45%、75%、25%。生命不高于 50% 时加 15 个百分点，不高于 25% 再加 10 个百分点，最高 95%。按钮显示当前成功率。
- 捕获成功后怪物离开敌方阵列，归捕获者所有。可收藏多只，每人同时出战 1 只；第一次捕获自动设为出战，下场战斗开始加入。
- 出战宠物按速度拥有独立回合，自动普通攻击与物种技能，获胜后得到成长经验。成长倍率暂定普通 1.00、宝宝 1.12、变异 1.25。团子恢复主人气血，乌龟保护主人，狼和野猪强化攻击，猴子连续两击；辅助招式冷却3回合。
- 宠物页显示实际参战属性、成长、经验与物种技能，可改名（1—12字）、出战或休息。收藏多只宠物时仍只允许一只出战。
- 人物、宠物、装备、药品、气血法力及共享队伍/战斗写入 `work/first-map-v1-state.json`。重启本地服务可恢复队伍与战斗；离线人物由AI接管，在线人物等待自己的指令。存档含本地会话信息，请勿公开上传；交付资源包不含试玩存档。

## 行囊与补给

行囊统一展示装备和恢复药品，可筛选“全部 / 装备 / 恢复药品”。装备可前往装备页穿戴和比较。新人物及首次迁移旧存档各获得3份回春散、3份灵露，耗尽不会重发；胜利可获得个人药品掉落。

| 药品 | 恢复效果 | 使用 |
| --- | --- | --- |
| 回春散 | 80点气血 | 地图给自己；战斗给一名存活己方人物或宠物 |
| 灵露 | 40点法力 | 地图给自己；战斗给一名存活己方人物 |

战斗服药消耗一次人物行动，由使用者扣除库存；目标资源已满、库存不足或未轮到自己时不能使用。气血和法力消耗保留至战后，下场战斗不会自动补满。驿站120地图单位范围内可免费休整，败退或撤退回驿站后恢复。换装备、切换试玩等级或升级时调整资源上限并保留已损失量。

## 装备

地图右侧点击“装备”，可逐件穿戴、替换、卸下，或“一键穿戴”每个部位当前符合等级与职业要求、加成最高的装备。面板显示人物立绘、六个部位、背包筛选、基础属性与装备加成；选中物品后可比较它与当前装备的差值。穿戴物品仍属于背包，替换不会丢弃或复制旧物品。

| 部位 | 加成 | 使用要求 |
| --- | --- | --- |
| 武器 | 攻击 / 术力 | 剑士用剑、刀客用刀、刺客用双匕、法师用法杖、医师用药葫芦 |
| 头饰 | 气血 | 全职业通用 |
| 衣服 | 防御 | 全职业通用 |
| 腰带 | 气血 | 全职业通用 |
| 鞋子 | 速度 | 全职业通用 |
| 饰品 | 法力 | 全职业通用 |

新人物与旧存档均补发六件1级新手行装，初始放在背包，可自己穿戴；旧存档只补发一次，人物和宠物保留。试玩切换职业时保留装备，并为尚未领取过该职业武器的人物补发一件新手武器；职业或等级不符的已穿戴物品自动卸下。

装备有1、5、10、15级四档；团子、乌龟掉1级，狼掉5级，野猪掉10级，猴子掉15级。等级要求按人物当前等级校验。白色凡品、绿色良品、蓝色上品、紫色珍品、金色灵品的加成倍率为1.00、1.20、1.45、1.80、2.20，属性取整。

胜利后，每只被击败的怪物分别为各人物进行装备掉落判定：普通30%、宝宝45%、变异65%，每人每场最多获得2件。掉落武器匹配领取者职业，物品分别归入各自背包；结算页显示自己的战利品。捕获的怪物不掉装备，失败或撤退不发装备，重复结算不会重复发放。

加成在下场战斗开始时计入人物：攻击 / 术力影响普通攻击、职业技能及医师治疗；防御影响伤害抵扣；气血与法力提高上限；速度参与行动排序。进行中的战斗及结算页只能查看装备，返回地图后才能换装。装备窗口打开时暂停移动。

这一版包含穿戴、属性和掉落。强化、交易、制作和装备换装立绘尚未接入；已确认的人物立绘与动画素材保持原样。

## 人物与技能

沿用已确认的五职业形象和 v3 整幅人物图集：静止固定站姿，行走12帧/秒；普攻、施法、受击18帧/秒。人物图保持比例，未用拆肢形变。3级首个主动、5级被动、10级第二主动、15级终极自动开放；终极另需100怒气。普通攻击和技能分别结算伤害、法力、冷却与状态，不额外叠加一次普攻。

技能页可查看五职业的四个技能、解锁要求、法力、冷却及伤害/治疗说明，并对比普通攻击；被动满足条件自动触发。点击“试演技能”可查看画面、暂停或拖动进度，试演不消耗资源，也不改变实际职业或等级。战斗轮到自己时，可在该页直接释放本职业已解锁技能。

四个技能按人物等级自动成长，共三个阶段：

| 技能 | 一阶开放 | 二阶提升 | 三阶提升 |
| --- | --- | --- | --- |
| 第一主动 | 3级 | 12级 | 27级 |
| 第二被动 | 5级 | 16级 | 30级 |
| 第三主动 | 10级 | 20级 | 33级 |
| 第四终极 | 15级 | 24级 | 36级 |

二阶的原有效果数值为初阶的120%，三阶为初阶的140%，两次提升不连乘。普通攻击基础倍率不随技能阶位提高；被动仅在原有触发条件成立时增强。新增附加效果随阶位生效：剑士破甲、减速与剑伤；刀客护盾、回血与减伤；刺客追击减速、怒气与隐匿；法师灼烧、回蓝与阵法破甲；医师减速、回蓝、护佑与青莲护盾。具体目标、数值、持续回合见技能页及 `outputs/修仙日记-技能三段成长-v5.md`。

技能页显示当前阶段、下一次提升等级及三段效果对比；战斗指令、被动结算和技能试演使用同一份成长数据。阶段不需要手动学习，也不写入额外存档字段；升级或恢复存档后根据当前等级计算。法力、怒气消耗、冷却和目标数量沿用原技能规则。

15个主动/终极招式采用独立特效素材与蓄力、出招、命中、消散四段演出：剑士青岚剑气、刀客重斩裂岩、刺客暗影刃光、法师星火月阵、医师药草青莲。单体、多目标、连续命中、治疗、护盾与状态类招式分别呈现；月缚阵在无即时伤害时也显示法阵。演出时长1.1—2.85秒与服务回合等待保持一致，结束后固定站姿。伤害、治疗、法力恢复分别显示；护佑、破甲、持续伤害、回春、减速和护盾显示剩余回合。

点击“角色”可切换职业和 1—36 级检查区域与技能，宠物保留。剧情同伴等级跟随队长的试玩等级。正常战斗亦可获得经验升级。

## 当前制作范围

这是可运行的浏览器原型，包含本地 HTTP/SSE 共享队伍和战斗、五个系统面板及职业技能演出。新增怪物为完整透明立绘，以位移、闪白和伤害数字反馈行动，尚未制作怪物专属逐帧动画。

服务仅监听本机 `127.0.0.1`，目前可用同电脑多窗口测试。微信小程序适配、公网房间服务和账号系统尚未接入，资源包不是微信发布包。

## 文件与验证

`config.json` 配置地图等级与品质；`equipment.json`、`items.json`、`pet-skills.json` 配置装备、药品与宠物招式；`rules.mjs` 处理玩法，`server.mjs` 提供本地服务与存档；`game.js`、`systems-ui.js`、`skill-ui.js` 与样式文件为画面和操作；`combat-art.mjs` 提供固定站姿、招式时长与特效绘制。`assets` 包含地图、15张透明怪物图、装备SVG图标和透明技能特效图集，`sources` 保留地图与怪物原始生成图。试玩包同时提供五职业的25张动画图集与立绘，运行时按图集坐标播放；原始逐帧PNG和GIF未重复装入本包。开源参考及许可证记录在 `开源参考-20261005.md`，本轮参考实现思路，没有复制其源码或素材。

`character-animation-v3/skills.json` 保存五职业共20个技能的三段数值与附加效果，`skill-growth.mjs` 根据等级解析当前阶段。

运行规则与 HTTP 测试：

```powershell
node --test outputs/first-map-v1/rules.test.mjs outputs/first-map-v1/equipment.test.mjs outputs/first-map-v1/server.test.mjs outputs/first-map-v1/systems.test.mjs outputs/first-map-v1/combat-art.test.mjs outputs/first-map-v1/skill-growth.test.mjs
```

测试存档独立于正式试玩存档。本版检查结果见 `技能三段成长验证-20261005.json` 和 `技能三段成长自动测试结果-20261005.txt`；此前的五系统、装备、横屏和首版记录保留作为历史检查结果，区分自动测试、浏览器实测及仍待完成的微信环境验证。
